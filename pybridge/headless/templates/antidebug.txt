// Starts the target with the debugger masked from basic anti-debug checks.
//
// Uses x64dbg's built-in `hide` command, which patches the PEB of the debuggee:
//   PEB.BeingDebugged      -> 0
//   PEB.NtGlobalFlag       -> cleared debug bits (0x70)
//   process heap Flags/ForceFlags -> normalized
// Covers x64 and WoW64. For deeper hiding (NtQueryInformationProcess, timing
// APIs, exception swallowing, ...), load the ScyllaHide plugin alongside and
// pick a profile in its scylla_hide.ini (see examples/antidebug.py).
//
// The script runs the target to completion; adjust the `erun` block for an
// interactive session.

settingset Events, SystemBreakpoint, 1
settingset Events, TlsCallbacks, 0
settingset Events, EntryBreakpoint, 1
init "%TARGET%"

// Patch PEB as soon as the system breakpoint hits, before any user code runs
hide
log "[template] debugger hidden (PEB patched)"

// Example: also log IsDebuggerPresent / CheckRemoteDebuggerPresent calls
// without pausing, to see how often the target probes
bp kernelbase.IsDebuggerPresent
bpcond kernelbase.IsDebuggerPresent, 0
bplog kernelbase.IsDebuggerPresent, "[antidebug] IsDebuggerPresent #{d:$breakpointcounter} from {a:[csp]}"

bp kernelbase.CheckRemoteDebuggerPresent
bpcond kernelbase.CheckRemoteDebuggerPresent, 0
bplog kernelbase.CheckRemoteDebuggerPresent, "[antidebug] CheckRemoteDebuggerPresent #{d:$breakpointcounter} from {a:[csp]}"

erun
log "[template] done"
